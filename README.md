# Habeebah Sulayman — Mobile Software Engineer Portfolio

A clean, responsive developer portfolio built using **Next.js**, **TypeScript**, **React**, and **Tailwind CSS v4** with **Framer Motion** scroll animations.

Designed with the **"h." Monogram Brand Kit** palette — supporting both Light Mode (Beige `#F5EFE6`, Nude `#EADFCF`, Tan `#C9B79C`, Black `#141414`) and Dark Mode via native CSS `light-dark()` and `<meta name="color-scheme">`.

---

## 🎨 Visual Identity & Design System

* **Beige (`#F5EFE6`)** & **Black (`#141414`)**: Primary light/dark backgrounds and high-contrast text
* **Nude (`#EADFCF`)**: Elevated card surfaces and inverse logo lockup
* **Tan (`#C9B79C`)**: Monogram full-stop and warm accent highlights
* **Typography**: `Plus Jakarta Sans` for headings and technical badges; `Poppins` for body copy.

---

## ✨ Sections & Architecture

1. **Hero**: Concise positioning for Android, iOS, and Kotlin Multiplatform (KMP) engineering.
2. **About ("From microbiology to mobile")**: Background story and key highlights (Education, Remote availability, Interests).
3. **Selected Work ("Things I've built")**: Featured cards for **Rova** (`rovaai.app`), **Duplicate Contacts Remover**, **Spendly**, and **Smart Chef**, plus a **Playground** spotlight for *Tip Calculator*.
4. **Experience**: Career timeline at **Layer Axis** (Rova & Duplicate Contacts Remover) with mobile-friendly accordion cards.
5. **Case Studies ("How I think through problems")**: Structured Problem → Approach → Result breakdowns for real-time `StateFlow`/`flatMapLatest` search and Arabic's 6-form plural system.
6. **Stack / Skills**: Categorised chips across Mobile, Data & backend, Testing & tools, and Web.
7. **Testimonials**: Feedback from engineering and product collaborators.
